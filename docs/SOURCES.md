# Sources and attribution

## Public geographic data

Provider: Overture Maps Foundation.

- https://overturemaps.org/
- https://docs.overturemaps.org/getting-data/
- https://docs.overturemaps.org/getting-data/cloud-sources/
- https://docs.overturemaps.org/attribution/
- https://stac.overturemaps.org/catalog.json

The adapter reads item extents from each release's STAC collection and selects intersecting Parquet files. It stores only feature identifiers, geometry, and bounding boxes for map samples. The national-boundary query additionally filters by country, subtype, and land flags at the source.

Themes used: buildings, transportation, and divisions. Record identity is the feature ID within a pinned theme and release. Snapshot changes are observations between releases, not a history of every underlying edit.

Map data can include contributions from community, commercial, and public-sector sources. Consult the attribution page for each release and theme. The tested building collection declares ODbL-1.0. Code licensing does not replace database attribution or redistribution obligations.

Displayed attribution: © OpenStreetMap contributors, Overture Maps Foundation.

Large downloads and derived datasets are excluded from Git. Do not add them to releases without reviewing their applicable licenses. The offline tests use invented geometries.

## Synthetic operational data

Generated by this project with a fixed random seed. Includes fictional depot IDs, shipment IDs, event timestamps, coordinates, capacities, and service radii. There are no real customers, addresses, drivers, contacts, or shipment histories.

The initial scenario covers invented locations near Brussels. It is not a sample of actual logistics demand. No inference about building occupants or businesses is made.
